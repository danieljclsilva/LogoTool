## Observer method

Read each task outcome in ordinary language. Let the participant choose their
route. Record their first action, pauses, misunderstandings, exact words and any
help. If assistance becomes necessary, record its time and wording, then let the
participant continue. Distinguish independent success, assisted success and
incomplete tasks. Record elapsed time for each task.

Use a fresh participant for each browser where possible. Record prior exposure
when a participant repeats the flow. Synthetic practice assets can establish
workflow usability. A real measured product supplies physical acceptance evidence.

Observer checkpoints include finding the next action, understanding the scale
warning, distinguishing setup commit from saving a file, discovering View/Fit,
access to the whole model, correct logo/area selection, units and direction of
movement, and recovery after reopening.

## Customer tasks

Give the participant a prepared customer file or extracted hybrid package and
the approved artwork. Record the delivery form used.

| Task outcome to read | Independent / assisted / incomplete | Time and first action | Observations and help given |
| --- | --- | --- | --- |
| Open the supplied file and identify the product and option. | | | |
| Put the selected logo in the requested area. | | | |
| Make it the supplied width while keeping its original shape. | | | |
| Make it the supplied height while keeping its original shape. | | | |
| Make the deliberately different width and height supplied for this task. | | | |
| Return to the previous placement using Undo. | | | |
| Add a second logo, then remove it so only the original remains. | | | |
| Begin opening another project while keeping this draft available. | | | |
| Close or reload with an unsaved change, then continue the same work. | | | |
| Review the layout, confirm it, and save the file you would return. | | | |
| Reopen that saved file and show the same layout and measurements. | | | |

Observer checkpoints include discovering size controls, interpreting linked
width/height, finding optional instructions, understanding the diagram/photo
explanation, interpreting the replacement guard, choosing the intended file,
and understanding the confirmation and download states.

## Debrief and result

Ask the participant what they believed was saved, which file they would hand
over, what the size and shape controls meant, and where they were uncertain.
Record their words and the task that prompted each observation.
