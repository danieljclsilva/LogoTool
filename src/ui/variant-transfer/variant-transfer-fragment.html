Frame conventions are declared strings and are never guessed, normalized, or coerced. Reference rects are caller-supplied millimetre rectangles, never inferred from polygons, bounds, pixels, artwork size, or model geometry. Region rules (JSON array, millimetres)

One rule maps one source region to one target region. absolute-position copies the source centre verbatim into the target region frame and requires the declared frame conventions to match exactly. normalized-position maps through caller-supplied sourceRef/targetRef rectangles (both required); without proportionalDimensions the logo keeps its fixed size, with "proportionalDimensions": true it scales proportionally. A placement with no matching rule and no override fails the whole transfer atomically. The operator must declare every frame convention explicitly: the rules box starts empty ([]), nothing is inferred, and the examples below are illustrative only — not calibrated for this asset.

Rule and override examples (illustrative +Y-up values, not calibrated)

Absolute front-to-front (conventions must match exactly):

{
  "sourceRegionId": "front",
  "targetRegionId": "front",
  "strategy": "absolute-position",
  "sourceFrameConvention": "centre-mm-y-up",
  "targetFrameConvention": "centre-mm-y-up"
}

Normalized, fixed-size logo (default; dimensions copied verbatim):

{
  "sourceRegionId": "front",
  "targetRegionId": "front",
  "strategy": "normalized-position",
  "sourceFrameConvention": "centre-mm-y-up",
  "targetFrameConvention": "centre-mm-y-up",
  "sourceRef": { "originXmm": 0, "originYmm": 0, "widthMm": 200, "heightMm": 100 },
  "targetRef": { "originXmm": 10, "originYmm": 20, "widthMm": 300, "heightMm": 150 }
}

Normalized, proportional scaling (add only this flag):

{
  "sourceRegionId": "front",
  "targetRegionId": "front",
  "strategy": "normalized-position",
  "sourceFrameConvention": "centre-mm-y-up",
  "targetFrameConvention": "centre-mm-y-up",
  "sourceRef": { "originXmm": 0, "originYmm": 0, "widthMm": 200, "heightMm": 100 },
  "targetRef": { "originXmm": 10, "originYmm": 20, "widthMm": 300, "heightMm": 150 },
  "proportionalDimensions": true
}

Per-placement override (beats any rule; width/height/rotation default to the source values):

{
  "placementId": "PLC-0001",
  "targetRegionId": "front",
  "xMm": 85,
  "yMm": 57.5
}
