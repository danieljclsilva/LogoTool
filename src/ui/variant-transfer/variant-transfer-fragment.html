Copy a layout to another variant

Offline draft only — pending review, never approved. Freeze the current layout, describe how each area maps to the target variant, and preview the copy. The copy is preview/export only; the target variant's own layout is never changed.

Watch out for mirrored areas: exact copy needs the area conventions to match exactly and fails otherwise; proportional copy maps the numbers across as written without mirroring, rotating, or re-axising.

3. How areas map across (list of rules, in mm)

Write one rule per area pair. An absolute-position rule copies the layout position verbatim and needs the declared conventions to match exactly. A normalized-position rule maps through your sourceRef/targetRef rectangles (both required): the logo keeps its size unless you add "proportionalDimensions": true, which scales it proportionally. A layout with no matching rule and no override fails the whole copy. You must declare every convention yourself: the box starts empty ([]), nothing is guessed, and the examples below are illustrative only — not tuned for this model.

Rule and override examples (illustrative +Y-up values, not calibrated)

Absolute front-to-front (conventions must match exactly):

{
  "sourceRegionId": "front",
  "targetRegionId": "front",
  "strategy": "absolute-position",
  "sourceFrameConvention": "centre-mm-y-up",
  "targetFrameConvention": "centre-mm-y-up"
}

Normalized, fixed-size logo (default; dimensions copied verbatim):

{
  "sourceRegionId": "front",
  "targetRegionId": "front",
  "strategy": "normalized-position",
  "sourceFrameConvention": "centre-mm-y-up",
  "targetFrameConvention": "centre-mm-y-up",
  "sourceRef": { "originXmm": 0, "originYmm": 0, "widthMm": 200, "heightMm": 100 },
  "targetRef": { "originXmm": 10, "originYmm": 20, "widthMm": 300, "heightMm": 150 }
}

Normalized, proportional scaling (add only this flag):

{
  "sourceRegionId": "front",
  "targetRegionId": "front",
  "strategy": "normalized-position",
  "sourceFrameConvention": "centre-mm-y-up",
  "targetFrameConvention": "centre-mm-y-up",
  "sourceRef": { "originXmm": 0, "originYmm": 0, "widthMm": 200, "heightMm": 100 },
  "targetRef": { "originXmm": 10, "originYmm": 20, "widthMm": 300, "heightMm": 150 },
  "proportionalDimensions": true
}

Per-placement override (beats any rule; width/height/rotation default to the source values):

{
  "placementId": "PLC-0001",
  "targetRegionId": "front",
  "xMm": 85,
  "yMm": 57.5
}
