        Area geometry checks and downloads (power tools)

        How areas work, in detail: the reference point is physical (0,0). The X direction runs from that point toward the +X-side point; the other axis is the orthogonal projection toward the +Y-side point (the third point chooses the Y side; the picked spans need not be perpendicular); the normal is X cross Y. Oriented frames come from existing marked points only; there is no canvas picking here. The calibration download does NOT include areas.
